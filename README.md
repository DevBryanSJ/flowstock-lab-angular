## Descripción. -

Proyecto para la visualización y gestión de invetarios de cualquier negocio que maneje dicho sistema, ya sea a escala de negocio local/comunitario con poca necesidad de gestión, o para macro-empresas que manejan grandes cantidades de productos en venta o almacenes para su negocio.
Este proyecto fue creado para la experimentación y entendimiento práctico de manejo de estados y reactividad de UI con Angular 21 o superior.

## Arquitectura de Proyecto. -

Este proyecto se usó Feature-First Architechture con el mótivo de establecer las mejores bases de código-limpio para una posible escalabilidad de este proyecto y sus funcionalidades.
